A few things worth knowing.

Does everything stay on my Mac?

Local model inference and your default chat history stay on your Mac. Widget feeds, web tools, Telegram, update checks, and enabled external integrations use the network. The optional Claude bridge sends context to Claude when enabled. Connecting an MCP client can also expose the context you allow to that client. Review the app’s Data & Network card and integration settings.

Will it work on my Mac?

Hermes requires Apple Silicon and macOS 14 or later. The default model needs about 25 GB of free disk; 32 GB of memory is comfortable and 64 GB gives more room. First launch recommends a model based on your hardware. You also need Python 3.12+, Xcode command line tools, and the separately installed Hermes Agent CLI.

Is there a subscription or an API bill?

Hermes Assistant is MIT licensed and local inference does not require an inference API key or per token payment. Optional external services, including Claude, may have their own costs and terms. Model weights have their own licenses.

Can I download a ready made app?

The current setup builds the native app from source using the installer. A bundled, signed, notarized DMG is on the roadmap. The current app is ad hoc signed; follow the repository’s first launch instructions.

How much control do I have over the agent?

Hermes exposes its tool activity, memory, and skills. Action classes support Auto, Ask, and Never settings with safety floors. Risky actions wait for your approval. Some connections are disabled by default, and Google mail access has no send capability.
